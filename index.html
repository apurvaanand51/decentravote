This dashboard runs entirely in your browser with no network or wallet required. The blockchain layer (blocks, transaction hashes, VoteCast events) is simulated to demonstrate the DecentraVote contract logic. In production the same logic runs as a Solidity smart contract on an Ethereum-compatible test network, called from a React front end via ethers.js. Candidates and voters shown here are fictional. This is a prototype — not a system for running real, binding elections.
